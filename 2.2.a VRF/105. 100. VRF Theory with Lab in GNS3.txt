🔴2.2.a VRF
############

🔴Remarks : 
------------
🔹we called VRF if we are using it with MPLS instead of that we are calling/using it "VRF Lite".

🔴VRF Lite:
-----------
🔹are like VLANs for touters, instead of using a single global routing table we can use multiple virtual routing tables, each interface of the router is assigned to a different VRF.

🔴20 VRF Lab:
-------------
🔹show commands:
----------------
	- show ip route vrf (vrf name)

!ISP Configuration
en
conf t
hostname ISP

ip vrf vrf_group_01
exit
ip vrf vrf_group_02
exit

int fa0/0
ip vrf forwarding vrf_group_02
ip add 199.1.4.2 255.255.255.252
no shut

int fa0/1
ip vrf forwarding vrf_group_01
ip add 199.1.3.2 255.255.255.252
no shut

int fa2/0
ip vrf forwarding vrf_group_01
ip add 199.1.2.2 255.255.255.252
no shut

int fa1/0
ip vrf forwarding vrf_group_02
ip add 199.1.1.2 255.255.255.252
no shut
exit

router ospf 1 vrf vrf_group_01
network 199.1.2.0 0.0.0.3 area 0
network 199.1.3.0 0.0.0.3 area 0


router ospf 2 vrf vrf_group_02
network 199.1.1.0 0.0.0.3 area 0
network 199.1.4.0 0.0.0.3 area 0
