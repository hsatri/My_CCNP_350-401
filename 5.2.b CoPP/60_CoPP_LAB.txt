🔴R1 CoPP Configuration : to stop UDP DOS Attack
=========================
ip access-list extended test01
permit udp any any

class-map cmap
match access-group name test01
exit

policy-map cmap
class cmap
! Rate limit to 8000 bits per second (bps)
police 8000 conform-action transmit exceed-action drop
exit
exit
exit

control-plan 
service-policy input pmap
