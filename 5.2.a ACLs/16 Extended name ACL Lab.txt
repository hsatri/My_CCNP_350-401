🔴Lap time:
===========

1. Configure Telnet in R2

2. Check All PCs can Telnet to R2 and Ping R1 and R2

3. Configure and Apply named extended ACL on R1 as follow

	a) Permit Telnet from PC1 to R2. Telnet to R2 must be denied for all other pcs in the network.
	b) Permit ping from PC2 to R2. Ping to R2 must be denied for all other pcs in the network.

🔴Basic Configuration: 
--------------------
! R1 configuration 
en
conf t
hostname R1
Router ospf 1
int e0/0
ip add 192.168.2.1 255.255.255.0
ip ospf 1 area 0
no shut

int e0/1
ip add 192.168.3.1 255.255.255.0
ip ospf 1 area 0
no shut
exit

int e0/2
ip add 192.168.1.1 255.255.255.0
ip ospf 1 area 0
no shut
exit


! R2 configuration 
en
conf t
hostname R2
router ospf 1
int e0
ip add 192.168.3.2 255.255.255.0
ip ospf 1 area 0
no shut

🔴 a) Permit Telnet from PC1 to R2. Telnet to R2 must be denied for all other PCs in the network
    b) Permit ping from PC2 to R2. Ping to R2 must be denied for all other pcs in the network:
-------------------------------------------------------------------------------------------------
! R1
en
conf t
ip access-list Extended Perm_Tel_PC1_R2
permit tcp host 192.168.1.2 host 192.168.3.2 eq 23
deny tcp any host 192.168.3.2 eq 23
permit icmp host 192.168.1.3 host 192.168.3.2 echo
deny icmp any host 192.168.3.2
permit ip any any
exit

int e0/1
ip access-group Perm_Tel_PC1_R2 out
