🔴Part 1 Simple configuration for each network : 
-------------------------------------------------
! R1 configuration 

en
conf t
hostname R1
int e0/0
ip add 1.1.1.1 255.255.255.252
no shut

int e0/1
ip add 192.168.1.1 255.255.255.0
no shut
exit

ip dhcp pool LAN01
network 192.168.1.0 255.255.255.0
default-router 192.168.1.1
exit

router ospf 1
int range e0/0-1
ip ospf 1 area 0


-----------------------------------

en
