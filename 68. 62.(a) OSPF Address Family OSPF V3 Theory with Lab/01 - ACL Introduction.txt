🔴5.2.a ACLs 
#############


🔴Access Control List : 
-----------------------
🔹Allow|Deny -> Network Traffic 
🔹filters which allow us to control traffic 
🔹its L3 Security.
🔹processed from top to down in sequential order list.
🔹Every ACL has a default deny statement at end of it.
	-> if a packet does not meet with any conditions, it will be destroyed by default deny.
🔹Empty ACL will permit all traffic by default.
🔹filter only the traffic passing from interface.
🔹Standard ACL:
	-> filter only the source IP address.
	-> should be placed near the DST devices.
🔹Extended ACL:
	-> placed near the SRC devices.
🔹Creat an ACL globally and then assign it to an interface.

🔴Different Types of ACL as given below:
----------------------------------------
🔹Standard
🔹Extended
🔹Time-Base ACL


🔴Different between Standard|Extended: 
---------------------------------------
1- Standard ACL:
	-> number range: 1-99 | 1300-1999
	-> Block: Host, Network, Subnet.
	-> Implemented Closest to the DST.
	-> filtering based on SRC IP @.
	-> all services are block.

2- Extended ACL:
	-> number range: 100-199 | 2000-2699
	-> Block: Host, Network, Subnet, Services.
	-> Implemented Closest to the SRC.
	-> filtering based on (SRC, DST, Protocols, Port Nmbr).
	-> Selected services can block.

🔴Different between Numbered|Named ACL: 
----------------------------------------
1- Numbered ACL:
	-> cannot be deleted specifically one rule -> should delete the whole acl list.
	-> if we try to delete a rule from a access list then the whole access list will be deleted.

2- Named ACL:
	-> Name is assigned to odentify an access list.
	-> we have the ability to delete a rules on the access list.
