🔴Differences between routing and routed protocols:
---------------------------------------------------
	+ Routed :  (e.g., IPV4,IPV6) carries user data across networks.
	+ Routing : (OSPF, BGP ...) determines the best path for data to travel.
	
	+-------------------+--------------------------------------+
	| Routed Protocol  | Routing Protocols                     |
	+-------------------+--------------------------------------+
	| IP, IPV4, IPV6   | RIP V1, RIPv2, OSPF, EIGRP, BGP, ISIS |
	+-------------------+--------------------------------------+


🔴Types of Routing:
-------------------
	1. Static Routing  
   	├── Manually configured routes  
   	├── No automatic updates  
   	└── Example: Static route (IP route command)

	2. Default Routing  
   	├── A single route used for unknown destinations  
   	├── Common in stub networks  
   	└── Example: Default route (0.0.0.0/0)

	3. Dynamic Routing  
   	├── Routes updated automatically  
   	├── Adapts to network changes  
   	├── Categories:  
   	│   ├── Distance Vector  
   	│   │   ├── RIP (Routing Information Protocol)  
   	│   │   └── IGRP (Interior Gateway Routing Protocol)  
   	│   ├── Link State  
   	│   │   ├── OSPF (Open Shortest Path First)  
   	│   │   └── IS-IS (Intermediate System to Intermediate System)  
   	│   └── Path Vector  
   	│       └── BGP (Border Gateway Protocol)
   	└── Used in large and scalable networks


🔴Static Routing:
-----------------
	+ Configured by admin manually.
	+ secure and fast.
	+ we should know the Dst Network ip
	+ its used in a small networks
	+ (AD) Administrative Distance = 1
	+ not support VLSM only class full.


🔴 Static Routing Configuration:
--------------------------------
	⚙️ CLI(config)#ip route (DST NET) (DST SUBNET MASL) (Next-Hop IP @)


🔴Floating Static Route: [LAB: CCNP ENCOR/00 Floating Static Route]
------------------------
	+ We have to change the AD to be highst than the primary root.
	+ are used for redundancy in-case an interface fails.
	⚙️ CLI(config)#ip route (DST NET) (DST SUBNET MASL) (Next-Hop IP @) (AD-Nmbr)


🔴 Default Route:
-----------------
	+ it is manually configure single route for entire DST.
	+ use to go internet.
	+ last preferred route in the routing table.
		-> when there is no entry for DST net in routing table then route forward to the default route.
	+ help to reduce the routing table size. 
	
	⚙️ Configuration :
	------------------
		- CLI(config)#ip route 0.0.0.0 0.0.0.0 (Next-Hop IP @)

🔴 Host Route:
--------------
	+ where DST @ is specific devices IP with a subnet mask of /32 for IPV4 and /128 for IPV6.
	+ a host route is used to route traffic to a specific host.
