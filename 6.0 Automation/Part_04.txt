🔴SDN(Software Defined Networking) :
------------------------------------
🔹is a network architecture approach that enables the networkto be intelligently and centrally controlled or progremmed by using software application.
🔹Use a central controller fpr the control plane.
🔹it can be physical hardware device or virtual machine.
🔹Northbound(NBI)
	➤ used to access the SDN itself.
	➤ allow network administrator to access the SDN to configure it or to retrieve information from it.
	➤ via GUI, 
	➤ offer API which allows other apps access to SDN controller.
	➤ we can use this towrite scripts and automate network.
	➤ Typically REST is Northbound interface.
🔹Sothbound(SBI)
	➤ SDN has to communicate with our network devices
	➤ OpenFlox, Cisco OpFlex, REST, NETCONF, RESTCONF, SSH
🔹NBI and SBI : Are not a physical interface (API, ...)
🔹Open Daylight : it is an Open source SDN controllser hosted by the linux foundations.
🔹CISCO SDN controllers is APIC(Application Policy Infrastructure Controller) is design to manage Data center
	➤ is DNA Center, it is design to manage entreprise environments like branch, campus and WAN.
