What is a firewall?	A security system (hardware, software, or cloud-based) that monitors and filters incoming/outgoing traffic based on security rules.
Where is a firewall typically placed?	Between a trusted and an untrusted network to prevent unauthorized access.
What is the main function of a firewall?	Traffic Control: Grants or blocks access based on predefined firewall policies.
What types of firewalls are mentioned in the document?	Hardware<br>Software<br>Virtual<br>Cloud-based
What was the evolution of firewall generations?	First Generation: Used packet filtering techniques<br>Second Generation: Introduced application-layer filtering
What environments use firewalls for protection?	Both home and corporate networks to protect from cyber threats.
What is state tracking in a stateful firewall?	Maintains connection states in a state table.
How does a stateful firewall handle packets?	Forwards packets after storing connection details.
What is replay matching in a stateful firewall?	Checks replay packets against the state table.
How does a stateful firewall implement security control?	Accepts matching packets<br>Drops unmatched ones
What features enhance a next-generation firewall (NGFW)?	Application awareness<br>Intrusion prevention<br>Cloud-based threat intelligence
What are the four generations of firewalls?	First Gen: Packet filtering<br>Second Gen: Deep packet inspection<br>Third Gen (Next-Gen): Layer 7 filtering, user/content policies<br>Fourth Gen: Cloud-based security and control
What is TrustSec?	A next-generation access control solution for managing firewall rules and ACLs.
What is SGT in TrustSec and how is it used?	SGT (Security Group Tag): Used for ingress tagging and egress filtering to enforce access policies.
How does TrustSec handle authentication and authorization?	Cisco ISE assigns SGT tags via 802.1x, MAB, or WebAuth.
How is policy enforcement implemented in TrustSec?	Access control (Allow/Drop) is applied at the egress point based on SGT tags.
What is MACsec according to the document?	A Layer 2 encryption method (IEEE 802.1AE) that encrypts traffic hop-by-hop between MACsec peers.
What is the encryption scope of MACsec?	Traffic is encrypted only on the wire but decrypted inside switches for packet enforcement and QoS.
How does MACsec perform encryption/decryption compared to IPsec?	Uses onboard ASICs for hardware acceleration instead of offloading to a crypto engine like IPsec.
What does MACsec add to frame format?	Adds a 16-byte MACsec Security Tag and a 16-byte Integrity Check Value (ICV).
What is required for MACsec to work in a communication path?	All devices in the communication path must support MACsec for encryption to work.
What security mechanisms does MACsec use?	Uses GMAC for authentication and AES-GCM for authenticated encryption.
What is 802.1X (Dot1x)?	A standard developed by the IEEE 802.1 working group. It is a port-based authentication method used for network access control at the Data Link Layer (Layer 2) of the OSI model.
What protocol is used to encapsulate authentication messages in 802.1X?	EAPOL (Extensible Authentication Protocol over LANs)
What protocol does 802.1X rely on for communication between devices?	EAP (Extensible Authentication Protocol)
What type of authentication does 802.1X provide?	Port-level authentication that ensures only authenticated devices can access the network.
What type of traffic is allowed before 802.1X authentication is successful?	Only EAPoL traffic (used for authentication); all other traffic is blocked until successful credential verification.
What networks can 802.1X secure?	Both wired and wireless networks at the Data Link Layer (Layer 2).
What is a Supplicant in 802.1X?	The user or device requesting access to the network (wired or wireless).
What types of devices can be a Supplicant?	A client, host, or workstation connected through a network access switch. Examples include PCs, printers, fax machines, or IP phones.
What is required for a device to function as a Supplicant?	The device must run 802.1X client software.
What operating systems include a native supplicant?	All Windows operating systems come with a native supplicant for wired network connections.
What is the Authentication Server's role in 802.1X?	It processes authentication requests, authenticates the Supplicant (client or device), validates its identity, and informs the Authenticator whether to allow or deny network access.
What protocol does the Authentication Server typically use?	RADIUS
What is an example of an Authentication Server?	RADIUS servers like ACS (Access Control Server)
What is Web Authentication?	Authentication and authorization via an HTTP/HTTPS portal that automatically redirects users to the portal.
When is Web Authentication typically used?	Primarily for guests, visitors, and as a fallback for 802.1X. Works with both wired and wireless access.
How does the authentication flow work in Web Authentication?	Users are redirected to Cisco ISE for authentication, after which Cisco ISE sends a CoA (Change of Authorization) request to the Network Access Device.
What type of users is Web Authentication ideal for?	Interactive users with a web browser who manually enter credentials.
What's required for Web Authentication to function?	Proper configuration, such as redirection ACL and ISE authentication/authorization rules.
When is a client typically redirected to the web portal?	When clients fail authentication via Dot1x or MAB.
What determines guest login access in Web Authentication?	The authorization profile on the Authentication Server.
What authentication methods can work alongside CWA (Centralized Web Authentication)?	Dot1x and MAB
What must a switch support for CWA to function?	HTTP/HTTPS services and have a redirect ACL.
What is CWA often used for?	Centralized guest authentication and authorization.
At what OSI layer does Web Authentication operate?	Layer 3 (L3), as it requires an IP address.
What is MAB (MAC Authentication Bypass)?	Network access control at Layer 2 using a device's MAC address instead of 802.1X authentication.
When is MAB typically used?	For devices like printers and IP phones that don't support 802.1X.
What security weakness does MAB have?	It is less secure than other methods because it can be bypassed by MAC address spoofing.
How does MAB work?	When enabled, the switch learns the MAC address from the first frame, then checks it with the authentication server (e.g., ISE).
What are the two ways authentication can be based on in MAB?	Calling Station ID or Username & Password.
What is MAB typically used for and what can it integrate?	Typically used for single endpoint devices and can integrate dynamic settings like ACLs or VLANs.
Can MAB be used with other authentication methods?	Yes, it can be used alone or alongside other authentication methods like 802.1X.
