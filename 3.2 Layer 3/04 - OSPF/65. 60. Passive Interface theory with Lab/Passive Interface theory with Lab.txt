🔴 Passive Interfaces :
-----------------------
🔹when we enable the OSPF --> all the interfaces will be advertised in OSPF 
🔹The OSPF packets will be send all the interfaces instead of LAN network for exemple
🔹To stop the packets we use "passive-interface" command:
	-> restrict the outgoing advertisements only.
	-> stops both outgoing/incoming routing updates.

R1(config)#router ospf 1
R1(config-router)#pass
R1(config-router)#passive-interface e0/1
