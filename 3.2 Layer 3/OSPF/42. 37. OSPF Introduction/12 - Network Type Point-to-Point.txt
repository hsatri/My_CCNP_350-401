🔴 Point-to-Point Networks:
---------------------------
🔹used by twi directly connected routers.
🔹serial link connected with 2 routers using PPP(point-to-point protocol)
🔹does not select a DR or BDR.
🔹224.0.0.5 -> Multicast address for Hello packets.
🔹Timers :	
	- Hello = 10 sec
	- Dead  = 40 sec.
🔹Neighbor Discovers dynamically.


🔴 LAB: 12 - Network Type Point-to-Point.pkt:
---------------------------------------------
!R1 configuration 
EN
CONF T
hostname R1
int s0/3/0
ip add 10.0.0.1 255.255.255.0
no shut

router ospf 1
network 10.0.0.0 0.0.0.255 area 0

!R2 configuration 
en
conf t
hostname R1
int s0/3/0
ip add 10.0.0.2 255.255.255.0
no shut

router ospf 1
network 10.0.0.0 0.0.0.255 area 0
