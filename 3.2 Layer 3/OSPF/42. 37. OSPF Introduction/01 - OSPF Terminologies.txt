🔴BACKBONE:
-----------
🔹is a central point of this implementation--> erea 0
🔹router in this area required to maintain complete DB of entire network.
🔹All arreas in OSPF are needed to connect with this area(Area 0).

🔴Area off backbone:
--------------------
🔹is the extension of the backbone.
🔹Routers running in this area required to maintain specific DB instead of complete.


🔴Area Concept in OSFP:
-----------------------
🔹INTERNAL ROUTER : withing same area --> Routers received from other routers in the same area)
🔹BACKBONE AREA(AREA 0): Routers which have all their ospf interfaces in Area 0.
🔹ASBR(Autonomous system boundary router): Connect Different protocols 
🔹ABR(Area Border Router): it connect from different Area to Area 0 -> Ex: interface in other area and other interfae are in Area 0.
⚙️Configuration :
	#router OSPF 1
	#network (wildcard) (mask) area 0


🔴OSPF Router ID:
-----------------
🔹Every Router in OSPF net work needs the unique OSPF router ID.
🔹given a unique identity to the OSPF router.
🔹how can router id be selected:
	1. the highest router-id that configured manually.
	2. the highst ip on loopback interface.
	3. the highst ip on physical interface.

⚙️Configuration :
	#router OSPF 1
	#router-id 1.1.1.1
	
	-> #clear ip ospf process:  then try to reload or use for this to take effect.


🔴Link:
-------
🔹is an interface running OSPF routing protocol.
🔹when we add an interface in OSPF process, it will be considered as a link.

	
🔴State:
--------
🔹is the information associated with an interface.
🔹(link or interface) contains information such (IP@ /UP OR Down status / subnet / type of interface / type of network / BW / Delay / etc ...).
🔹OSPF consider this information as the state.


🔴LSA(Link State Advertisement):
--------------------------------
🔹is data packet.
🔹countains Link-State and routing information.
🔹OSPF use it to share ad learn network information.


🔴LSDB(Link-State Database):
----------------------------
🔹is collection of all LInk State Advertisment received by router.
🔹every LSA has a unique sequence number.
🔹OSPF stores LSA in LSDB with the sequence number.
