🔴OSPF States:
--------------
- OSPF has to get through 7 states in order to become neighbors.
1️⃣DOWN : no OSPF neighbors detected at this oment.
2️⃣INIT: The interface has detected a Hello packet coming from a neighbor(hos not yet been establish) --> [1 Side Hello]
3️⃣TWO-WAY: when Hello is exchanged between two ospf routers (2 side hello) --> DR/BDR is elected in this stage .
4️⃣EXSTART STATE: Beginning of the LSDB exchange between both routers. Routers will start to exchange link state information.(DBD exchange going on).
5️⃣EXCHANGE STATE: Routers will describe their entire link-state database by sending database description packets + packet could be flooded to other interfaces on the router (DBD Done).
6️⃣Loading State: actual database is a exchanged means that (LS-Request, LS-Update, LS-Achknowledgement) are also exchanged. (LSR/LSU/LSA)
7️⃣FULL STATE: 
	the adjacency is complete, the neighboring routers are fully adjacent. 
	the neighboring routers are fully adjacent.
	Adjacent routers will have a similar link-state database [Done]

⚙️Debugging commands :
	#debug ip ospf packet
	#u all  -> to undebug everything
	#debug ip ospf adjacency    -> turn on OSPF adjacency debugging 

⚙️Clearing commandes:
	#clear ip ospf process   -> reset All ospf processes.
