🔴EIGRP : 
---------
🔹 Overview:
- EIGRP is a Cisco-proprietary (now open-standard since 2013) advanced distance vector routing protocol.
- Often considered a hybrid protocol as it incorporates features of both distance vector and link-state protocols.
- Uses DUAL (Diffusing Update Algorithm) to calculate the best loop-free paths.
- EIGRP uses RTP (Reliable Transport Protocol) to ensure reliable delivery of updates.
- Event-driven protocol: only sends partial updates when topology changes (not periodic).
- Supports both IPv4 and IPv6 routing.
- Uses multicast address 224.0.0.10 to communicate with neighbors.
- Supports VLSM, CIDR, automatic and manual summarization.
- Supports equal-cost and unequal-cost load balancing (up to 32 paths, 4 by default).
- Default hello timer: 5 seconds (15 seconds for WAN/low speed links).
- Default hold/dead timer: 15 seconds.
- EIGRP supports MD5 and SHA authentication.
- EIGRP protocol number : 88

🔹 Administrative Distance (AD):
- Internal routes: 90
- External routes: 170

🔹 EIGRP Tables:
1. **Neighbor Table**: Stores information about directly connected EIGRP neighbors.
2. **Topology Table**: Stores all learned routes and their metrics from neighbors.
3. **Routing Table**: Stores the best routes (successors) selected by DUAL.

🔹 EIGRP Metric Calculation:
Default formula:
Metric = [(K1 * Bandwidth) + (K3 * Delay)] * 256

Default K-values:
K1=1, K2=0, K3=1, K4=0, K5=0
(Note: Only Bandwidth and Delay are used by default)

🔹 Bandwidth = 10^7 / minimum bandwidth (in Kbps)
🔹 Delay = Sum of delays (in tens of microseconds)

🔹 DUAL and Feasibility Condition:
- Successor: Primary route
- Feasible Successor: Backup route (RD < FD of current successor)
- RD = Reported Distance (from neighbor)
- FD = Feasible Distance (best known distance)

🔹 Load Balancing:
- Equal-Cost Multipath (ECMP): Default, up to 4 paths (can be increased to 32).
- Unequal-Cost Multipath: Enabled using the `variance` command.
```bash
Router(config-router)# variance <multiplier>
```

🔹 Authentication:
- Supports MD5 and SHA for neighbor authentication.

🔹 EIGRP IPv4 Configuration:
```bash
Router(config)# router eigrp <AS number>
Router(config-router)# network <network-address>
Router(config-router)# no auto-summary
Router(config-router)# passive-interface <interface>  # Optional to disable neighbor formation
```

🔹 EIGRP IPv6 Configuration (interface-based):
```bash
Router(config)# ipv6 unicast-routing
Router(config)# ipv6 router eigrp <AS number>
Router(config-router)# router-id <router-id>
Router(config)# interface <int>
Router(config-if)# ipv6 eigrp <AS number>
```

📌 Multicast address used: 224.0.0.10 (IPv4), FF02::A (IPv6)
📌 Supports route filtering, route maps, stub routing, and summarization.
