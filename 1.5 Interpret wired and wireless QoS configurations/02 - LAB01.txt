🔴How to conigure QoS: 
----------------------
	1. Class Map -> we use it ti match the traffic.
	2. Identify the traffic to apply special treatment.
	3. Creat POlicy (what type of treatment we need to apply.)
	4. Service policy => applying policy map

➤ QoS configuration
en
conf t
class-map http_map_fa00
  match protocol icmp
  exit
class-map icmp_map_fa00
  match protocol icmp
  exit
policy-map f0/0_in
  class http_map_fa00
  set ip dscp AF31
  exit
  class icmp_map_fa00
  set ip dscp CS1
  exit
  exit
int fa0/0
  service-policy in f0/0_in
