🔴HSRP(HOT STANDBY ROUTER PROTOCOL) : 
-------------------------------------
🔹CISCO Propriety.
🔹Two Version (V1 & V2) -> are not compatible with each other.
🔹At least 2 Routers. one (ACTIVE) and others (STANDBY)
🔹ACTIVE GATEWAY OF GROUP : Highest priority gateway ->the owner of the highest Ip address or the hight priority
🔹ACTIVE GATEWAY is the owner of Virtual MAC and Virtual IP @.
🔹the default priotity = 100 -> it can be change from (0-255).
🔹preempt option is disabled by default.
🔹HSRP V1
	-> 224.0.0.2 : sending HELLO
	-> allows for group numbers ranging from 0-255
	-> Virtual MAC @ : 0000.0c07.acXX 
🔹HSRP V2
	-> 224.0.0.102 : sending HELLO
	-> allows for group numbers ranging from 0-4095
	-> support IPV6
	-> Virtual MAC @ : 0000.0c9f.fXXX 

🔹SUPPORT AUTHENTICATION using (Clear TXT | MD5)
🔹Timers V1@V2:
	->Hello : 3 sec
	->Hold Time : 10 sec 


🔴HSRP State: 
-------------
🔹Initial:
	-> The beginning state.
	-> Indicates that HSRP does not run.
	-> entered via a configuration change or when interface first comes up.

🔹Listen:
	-> the router knows the Virtual IP @.
	-> router neither the active/Standby.
	-> it listen for hello msgs from those routers.

🔹Speak:
	-> Router sends periodic Hello msgs 
	-> Participates in the election of the ACTIVE/STANDBY.
	-> Router cannot enter speak state unless the router has the Virtual IP @.

🔹Standby:
	-> Keep sending Hello msgs.
	-> if the Acgive fails it will take over.

🔹Active:
	-> the router will actively forward packet from client and send Hello msgs.
