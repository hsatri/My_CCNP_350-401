🔴VRRP(Virtual Router Redundancy Protocol) : 
--------------------------------------------
🔹OPEN Standard.
🔹Timers:
	-> Hello : 1 sec
	-> Hold timer : 3 sec
🔹Uses terms Master/Backup (in HSRP: Active/standby).
🔹Master sends VRRP advertisements to other routers in the same group.
🔹224.0.0.18 : for Hello mechanism and elections(IPV4)
🔹0000.5E00.01XX : Virtual Mac @ (XX group Nmbr).
🔹transport protocol 112
🔹the preemption is enabled by default.
	-> can be desibled by : "no vrrp preempt" on the interface
🔹We can force a router to become the master:
	-> priority 255
🔹3 Version :
	-> V1 : 
	-> V2 : Support IPV4
	-> V3 : Support IPV4/IPV6
