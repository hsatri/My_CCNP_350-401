🔴EIGRP Metric Calculation
###########################


🔴EIGRP Metric : 
----------------
🔹EIGRP uses the metric to select the best route from all available routes for DST.
🔹Has 5 components :
	1 - BW
	2 - Load
	3 - Delay
	4 - Reliability
	5 - MTU
🔹Only BW and Delay are by default enabled.
🔹To check metric that EIGRP using for calculation you can :
	CLI#show ip protocols
🔹K1 --> (BW) 
	- EIGRP Picks lowest BW to the DST network.
	- is amount of the data that can be transmitted in a fixed amount of time.

🔹K2 --> Load
	- is a dynamic value that changes frequently.
	- its based on packet rate and BW of interface.
	- 1 = interface is empty
	- 255 = interface is fully utilized.
	- Data are flows in both directions:	
		* TXLOAD : 
		* RXLOAD : for incoming traffic.
🔹K3 --> Delay
	- To check the delay :
		CLI# show int e0/0
	- The time(sec) taked by a packet ib crossing the interface.

🔹K4 --> Reliability
	- dynamic value
	- it compares all successfully received frames against all received frames.
	- 100% reliability indicates that all the frames, which we recieved were good
		-> not have any issue with physical link.
	- if we have any issue physcal link this value will be decrease.

🔹K5 --> MTU(Maximum Transmission Unit)
	- advertised with routing update but it does not actively participate in metric calculation.

🔹To check the MTU, BW, DLY of the interface :
	- CLI# show int e0/0



🔴Autonomous System : 
---------------------
	- EIGRP shares  information only with neighbors.
	- to become a neighbor AS number must be matched .
	
🔴Path Metric Calculation : 
---------------------------
	- EIGRP METRIC = 256 * ((10^7/Min_BW)+(Delays of interface / 10)
	- To check the Metric :
		CLI# show ip route eigrp
