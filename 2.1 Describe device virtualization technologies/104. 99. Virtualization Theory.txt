🔴What is Virtualization : 
--------------------------
🔹Support running multiple virtual systems on a single physical machine.
🔹Provides flexibility and reduces costs.

🔴Server Virtualization : 
-------------------------
🔹We can use some software (hypervisor) to do virtualization.

🔴VM(Virtual Machine) : 
-----------------------
🔹is pretty identical to physical server except it's virtual.
🔹Virtual hardware(CPUs, memory, storages, ...) which run on a hypervisor.

🔴hypervisor : 
---------------
🔹is the server virtualization software that runs on the physical server .
🔹called also 'virtual machine manager'.
🔹allocates physical resources to each of systems & ensre do notinterrupt each other.
🔹we can creat VMs and configure how much (CPUs, memory, storage...) to give on each VM
🔹2 Typer (1 & 2).

🔴Type 1 hypervisor : 
---------------------
🔹runs directly on the system hardware.
🔹is commonly referred to as "Bare Metal".
🔹ex: (VMWARE. HYPER-V? REDHAT KVM ....)

🔴Type 2 hypervisor : 
---------------------
🔹Runs on top of an OS(MS windows, Linux, ...).
🔹used by client devices.
🔹ex: (vmware workstation, player, Virtual Box, QEMU).
🔹on Desktops
🔹VMWARE WORKSTATION , VIRTUALBOX.


🔴Virtual Switching : 
---------------------
🔹is a software-based L2 switch that operates like a physical ethernet switch.
🔹vSwitch enables VMs to communicates with each other within a virtualized server and with external physical networks through the physical network interface cards (pNICs).
🔹Most popular vswitches:
	- vsphere switch.
	- Cisco vSwitch(OVS).
	- cisco Nexus virtual switch.
