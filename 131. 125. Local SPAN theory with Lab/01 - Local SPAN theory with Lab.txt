🔴4.3 Configure SPAN/RSPAN/ERSPAN
##################################

===============================
🔴SPAN(Switched Port Analyzer): 
===============================
🔹use ti analyze the traffic for particular port.
🔹Copy all traffic from (rcv port, src vlan) to a dst interface.
🔹using wireshark to caprute traffic from an interface .
🔹Use for troubleshootng purpose and monitor network traffic.
🔹To monitor traffic for performing a security audit.
🔹Able to monitor a single interface or many.

🔴3 main types of SPANs supported on CISCO switches: 
----------------------------------------------------
🔹Local SPAN
🔹RSPAN
🔹ERSPAN

🔴Local SPAN: 
-------------
🔹when we use a DST interface on the same switch we called it SPAN.
🔹copies traffic from SRC interface to DST interface for analysis.
🔹(wireshark, linkshadow, ...) -> application we can use to analyses traffics.


🔴RSPAN(Remote Switch Port Analyzer): 
-------------------------------------
🔹SRC port(switch port, trunk, etherchannel) can be a routed port,
🔹monitor a remote interface that exsite on another switch.
🔹need to use VLAN for remote SPAN traffic.
🔹allows traffic that is sourced from switchto mirrored to a remote switch.


🔴ERSPAN(Encapsulation Remote Switch Port Analyzer): 
----------------------------------------------------
🔹Brings generic routing encapsulation GRE for all captured traffic.
🔹is used to send traffic for sniffing over L3 networks using GRE tunnel.
🔹Ethernet interface qre nit supported on ERSPAN configured as L2 interface.
