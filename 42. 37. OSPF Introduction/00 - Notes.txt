🔴OSPF(Open Shortest Path First):
---------------------------------
🔹standard
🔹Link state protocol -> its send the update when if the exmple a interface change etc....
🔹use IP protocol type 89.
🔹use SPF(Shortest Path First)algorithm.
🔹support unlimited hop count.
🔹Metric is COST |cost = 10^8/BW.
🔹OSPF EXT/INT AD=110
🔹suport VLSM/CIDR.
🔹support load balncing -> only if equesl paths cost.
🔹Concept of areas to ease mngmt and control traffic (to stop LSA).
🔹all the ears must connect to eara 0 .
🔹support Authentication.
🔹224.0.0.5 -multicast @ to send the Hello packet.
🔹224.0.0.6 -multicast @ for all desinated routers.
🔹Faster convergance.
🔹Timers:
	- Hello: 10 sec
	- Dead : 40 Sec.
🔹Routers send only changes and not the entire routing table on periodic update.
🔹Support IPV4/IPV6.
🔹Send all updates in the form of LSA(Link State Advertisement).
	- send it with the sequence Nbr: 0x80000001 -> 0x7FFFFFFF

⚙️Configuration :
	#router OSPF 1
	#network (wildcard) (mask) area 0
