🔴Enable Mode Passwords:
-------------------------
🔹CLI(config)#enable password cisco
	➤ The password are visible (not crypted)
🔹CLI(config)#service password-encryption
	➤ its encrypt password but its not a strong encryption 
	➤ we can easyly decrypte via ex: https://www.ifm.net.nz/cookbooks/passwordcracker.html

🔹CLI(config)#enable secret p@ssw0rd
	➤ also its weak encryption
	➤ we can dcrypte it by : https://www.ifm.net.nz/cookbooks/cisco-ios-enable-secret-password-crack.html

🔹For stronk encryption for password: 
	CLI(config)#enable algorithm-type sha256 secret (PW)
	or	
	CLI(config)#enable algorithm-type scrypt secret cisco
➤

🔴Virtual Terminal Line(VTY):
-----------------------------
🔹We are access network device virtually so we will use VTY.
🔹VTY is a CMD Line interface (CLI) created in a router.
🔹is way to access R/S CLI remotly
🔹are logical connections from the network to the R/S.

🔴Telnet:
---------
🔹Is a network protocol that provides a cmd line interface to communicate with a device remotly.
🔹is use to access device remotly from different locations.
🔹is an application layer protocol 
🔹Use TCP/23

🔴Telnet Configuration:
-----------------------
🔹Methode_1:
	Conf t
	Enable password 12345
	line vty 0 4  => if we want to allow (e.g 5 people to access simmilt)
	password (PW)
	login

🔹Methode_2:
	conf t
	username abc password abc
	enable password 12345
	line vty 0 5
	password cisco

🔴SSH(Secure Shell):
--------------------
🔹is a secure methode for remote access as is include authentication and encryption
🔹Uses an RSA Public/Private key pair.
🔹TCP/22
🔹Very secure
🔹there is 2 version : V1/V2
	-> V2 is more secure than V1.
🔹by default V1 enabled

🔴Steps to Confiure SSH on CISCO IOS:
-------------------------------------
🔹Step_01:
	hostname HN01

	ip domain name satri.ma
	
	Crypto key generate rsa
		-> name of the key : A1.satri.ma
		-> key size : 2048
		-> General purpose keys : 1024
	
	ip ssh version 2
	
	line vty 0 1
	transport input ssh 
	login local
	username admin password admin

🔹how to access :
	ssh -l (username) (IP)
	password

🔴Cisco Routers password Types:
-------------------------------
Cisco Password		| Crackability
------------------------------------------------------
Type 0			| Instant
------------------------------------------------------
Type 7			| Instant
------------------------------------------------------
Type 4			| easy
------------------------------------------------------
Type 5			| medium
------------------------------------------------------
Type 8			| hard
------------------------------------------------------
Type 9			| very hard
------------------------------------------------------

🔹Type 0 : enable password cisco123
	➤ password will not be encrypted:
	➤ store it un RUN/START files 

🔹Type 4 : 
	➤ password will be encrypted when R/S store it in RUN/Start files
	➤ using SHA-256
	➤ can be cracke but will take long time

🔹Type 5 :
	➤ password will be encrypted when router store it in  RUN/Start files using MD5
	➤ can be cracke but will take long time
	➤ The hash of the password.

🔹Type 7 :
	➤ password will be encrypted when router store it in  RUN/Start.
	➤ Using Vigenère Cipher
	➤ easy to decrypt there is a websites who can using it to decrypt it less than 1 sec.
	
🔹Type 8 : 
	➤ password will be encrypted when router store it in  RUN/Start.
	➤ Using PBKDF2-SHA-256.
	➤ Secure Hash algorithm
	➤ 26-bits (SHA-256)
	➤ "enable algorithm-type sha256 secret cisco123"

🔹Type 9:
 	➤ password will be encrypted when router store it in  RUN/Start.
	➤ Using scrypt: hashing algotithm
	➤ "enable algorithm-type scrypt secret cisco123"
