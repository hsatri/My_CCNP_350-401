🔴Basic configurtion:
----------------------
! R1 Config
enable
configure terminal
hostname R1
int e0/0
ip add 192.168.200.1 255.255.255.0
no shut
exit


! R2 Config
enable
configure terminal
hostname R2
int e0/0
ip add 192.168.200.2 255.255.255.0
no shut
exit


🔴BGP configurtion:
--------------------
! R1 IBGP Config
router bgp 1
neighbor 192.168.200.2 remote-as 2

! R2 IBGP Config
router bgp 2
neighbor 192.168.200.1 remote-as 1


🔴Verfication_01:
-----------------
show ip bgp neighbors | include host

R1#show ip bgp neighbors | include host
Local host: 192.168.200.1, Local port: 54381
Foreign host: 192.168.200.2, Foreign port: 179

R2#show ip bgp neighbors | include host
Local host: 192.168.200.2, Local port: 179
Foreign host: 192.168.200.1, Foreign port: 54381


R1 --> Active(client)
R2 --> Passive(server)


clear ip bgp * : cmd to reset the bgp neighbor ADJCHANGE 

🔴BGP ACTIVE / PASSIVE configurtion:
------------------------------------
!R1
en
conf t
router bgp 1
neighbor 192.168.200.2 transport connection-mode passive
end
clear ip bgp *

!R2
en
conf t
router bgp 2
neighbor 192.168.200.1 transport connection-mode active
end
clear ip bgp *

🔴Verfication_02:
-----------------
R1#show ip bgp neighbors | include host
Local host: 192.168.200.1, Local port: 179
Foreign host: 192.168.200.2, Foreign port: 33121


R2#show ip bgp neighbors | include host
Local host: 192.168.200.2, Local port: 33121
Foreign host: 192.168.200.1, Foreign port: 179


==> Now the status are changed 
	R1 --> Passive(server)
	R2 --> Active(client)
