==> you can see also the destination 11.11.11.0 are have the weight 500 via 192.168.102.2 which we are not specified it for it .
==> 2.2.2.0/24 next hop should be 192.168.102.2 | 11.11.11.0/24 next hop should be 192.168.103.2

! R1 reconfig the weight :
en
conf t
router bgp 1
no neighbor 192.168.102.2 weight 500
do clear ip bgp * soft

! R1 Route-Maps :
access-list 1 permit 11.11.11.0 0.0.0.255
route-map Lab50 permit 10
match ip add 1
set weight 500
exit
route-map Lab50 permit 20
set weight 0
exit

router bgp 1
neighbor 192.168.103.2 route-map Lab50 in
do clear ip bgp * soft
