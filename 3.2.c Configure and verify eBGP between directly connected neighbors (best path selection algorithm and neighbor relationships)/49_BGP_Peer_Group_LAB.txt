🔴BGP configurtion:
--------------------
! R1 Configuration
ip route 2.2.2.0 255.255.255.0 192.168.102.2
ip route 3.3.3.0 255.255.255.0 192.168.103.2
ip route 4.4.4.0 255.255.255.0 192.168.104.2
router bgp 1
neighbor 2.2.2.2 remote-as 2
neighbor 3.3.3.3 remote-as 3
neighbor 4.4.4.4 remote-as 4
network 1.1.1.0 mask 255.255.255.0
! R1 peer group
neighbor gp1 peer-group
neighbor 2.2.2.2 peer-group gp1
neighbor 3.3.3.3 peer-group gp1
neighbor 4.4.4.4 peer-group gp1
neighbor gp1 update-source loopback 0
neighbor gp1 ebgp-multihop 2
