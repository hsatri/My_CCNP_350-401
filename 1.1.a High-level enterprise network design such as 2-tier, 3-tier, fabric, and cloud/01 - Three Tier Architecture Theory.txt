🔴1.1.A High-level enterprise network design such as 2-tier, 3-tier, fabric, and cloud
########################################################################################


🔴3-Tier : 
----------
🔹Great solution for large entreprise.
🔹Consists of there layers.
🔹= Core Layer + Distribution Layer + Access Layer.

🔴2-Tier : 
----------
🔹For small to medium-size networks.
🔹CORE/Distribution can be combined into one.
🔹reduce the network cost.


🔴Core Layer : 
--------------
🔹Biggest, fastest and most expensive routers with highst model.
🔹Is the one coordinating everything.
🔹is backbone of networks.
🔹talk with distribution using dynamic routing protocols.
🔹provides : high-speed switching, reliability, fault tolerance.


🔴Distribution Layer : 
--------------
🔹Located between the access L and CORE.
🔹can defined the policy for networks --> ACLs and filtering.
🔹can provide the aggregation of LAN or WAN links.
🔹Routing between LANs and VLANs.
🔹Redundancy, load balancing, aggregation, summarization.
🔹is the smart Layer on the Layer model.
🔹Routing, filtering, QOS, ...
🔹called the workgroup also.

 🔴Access Layer : 
-----------------
🔹closer to the users.
🔹referred as the network edge.5users and the endpoint connected to this layer).
🔹it provides high BW using wirdes/wireless access.
🔹includes the access switches.
🔹connected the users to the network
🔹security policies if we want to enforce in order to allow access to the network.(port security,  ...).
🔹also provides : QOS Classification, ARP inspection, STP, POE, VLANs ....

🔴Benefits of Hierarchical Model : 
---------------------------------
🔹Creating High performance networks.
🔹Isolates causes of network trouble and issue.
🔹3 Layer Network model
	➜ Better filter 
	➜ Policy creating application.
	➜ Efficiently accommodate future growth.
	➜ Redundancy and availability.
🔹if one switch is down , we have another alternate path to reach the DST.
🔹we can add more distribution or access later switches.

🔴Fabric Capacity Planning : 
-----------------------------
🔹Ensuring that the network has the resources it needs to prevent an impact on business-critical applications.
🔹Is and overlay network(Virtual network) built over underlay network(physical network) such as (VXLAN).
🔹enabling :
	➜ Host mobility.
	➜ Network automation
	➜ Network virtualization
	➜ Segmentation
	➜ Flexible
	➜ Secure
🔹Now we have NG overlay fabric technology : 
	➜ SDN : for campus
	➜ SD-WAN : for WAN network
🔹CISCO SD-Access : Designed for enterprise campus and branch network environments and not for other types such data center, service provider and wan environments
🔹SDWAN fabric : is cloud-based WAN solution for enterprise and data center networks.
