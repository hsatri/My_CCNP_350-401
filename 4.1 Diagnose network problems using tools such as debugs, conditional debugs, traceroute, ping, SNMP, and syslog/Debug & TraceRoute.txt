🔴Debug and Conditional Debug: 
------------------------------
🔹Debug:
	➤ Useful tools when troublshooting specifivc issues.
	➤ Help to show the real time information on device.
	➤ to keep track in case of events or protocol errors.
	➤ to keep track the internal msgs taking place.
	➤ Turn on debugging for all interfaces --> can produce a huge amount of information which overload the router.
	
🔹Conditional Debug:
	➤ Is very useful to filter out some of the debug information.
	➤ Generates debugging messages for one interface/sub-int.
	➤ to limit information based on specific interface or protocol.
	➤ using "no debug all" or "undebug all" does not remove the condition debugging.

🔴Debug Commands: 
------------------
🔹CLI#debug ip icmp  => enabling debug for icmp packets
🔹CLI#debug ip packet
🔹CLI#debug interface
🔹CLI#debugeigrp packets hello
🔹CLI#show debug condition

🔴condition Debugging Commands: 
-------------------------------
🔹CLI#debug condition ?
🔹CLI#debug condition int f0/0
🔹CLI#undebug condition interface f0/0
🔹CLI#show debugging
🔹CLI#no debug all
