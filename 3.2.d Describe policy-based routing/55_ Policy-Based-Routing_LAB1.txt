- we will configure PBR in the way traffic to the DST 8.8.8.8 will directed to R3
- 4.4.4.4 via R4

🔴 R2 PBR configuration :
#########################
en
conf t
! step_01 : creat ACL with the selecting the chosing src and dst
ip access-list extended ACL01
permit ip host 192.168.12.1 host 8.8.8.8
exit

! create the route map
route-map PBR_8_R3 permit 10
match ip address ACL01
set ip next-hop 192.168.23.1
exit

! Applying the policy in the correct interface 
int fa0/1
ip policy route-map PBR_8_R3
